# AI Interview Agent

A FastAPI-based backend and modern web UI for an automated AI interview agent powered by Groq integration.

## Features
- **FastAPI Backend:** Handles interactive candidate assessments and communication with the Groq API.
- **Dynamic Frontend UI:** Clean, modern dark-themed chat interface that displays real-time messages and structured feedback report cards.
- **Automated Workflow:** Auto-initializes sessions and transitions smoothly through interview steps.

## Tech Stack
- **Backend:** Python, FastAPI, Uvicorn, Groq API
- **Frontend:** HTML5, Tailwind CSS, Vanilla JavaScript
